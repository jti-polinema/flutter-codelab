Codelabs: Pemrograman Mobile

Modul praktikum berbasis codelab untuk mata kuliah Pemrograman Mobile dengan fokus pada Flutter modern, state management, REST API, local storage, FCM, testing, deployment, keamanan aplikasi, serta penggunaan AI secara bertanggung jawab dan terukur.

#01 Minggu 1 - Mobile Development Ecosystem & Flutter Refresh

Memahami ekosistem pengembangan mobile, arsitektur Flutter, refresh Dart dasar, dan kesiapan environment kerja untuk praktik pemrograman mobile.

#02 Minggu 2 - Declarative UI & Responsive Design

Menguasai widget dasar, layout responsif, material design, theme, serta prinsip UI deklaratif pada Flutter.

#03 Minggu 3 - Navigation & State Management

Mampu membangun navigasi dan menerapkan state management dasar dengan Riverpod serta loading/error/success state.

#04 Minggu 4 - Networking & REST API

Mengintegrasikan HTTP, Dio, JSON, model data, repository, menangani loading dan error pada aplikasi mobile.

#05 Minggu 5 - Local Storage & Offline First

Mampu menerapkan SharedPreferences, Hive/SQLite, cache, dan pola offline-first untuk penyimpanan data lokal.

#06 Minggu 6 - Authentication, Security & FCM Coming Soon

Menerapkan autentikasi, keamanan dasar, dan Firebase Cloud Messaging untuk notifikasi real-time yang aman.

#07 Minggu 7 - Clean Architecture Coming Soon

Menata project dengan prinsip SOLID, layer separation, repository, use case, dan dependency injection.

#08 Minggu 8 - Mid Project Review & Code Review Coming Soon

Melakukan review kode, GitFlow, pull request, static analysis, dan evaluasi progress project di tengah semester.

#09 Minggu 9 - AI-assisted Development / Vibe Coding Coming Soon

Menggunakan AI coding assistant secara bertanggung jawab, memvalidasi output AI, serta memperbaiki hasilnya dengan pemahaman teknis.

#10 Minggu 10 - AI Feature Integration Coming Soon

Mengintegrasikan fitur AI seperti chat, prompt, OCR, atau speech-to-text ke dalam aplikasi mobile yang relevan.

#11 Minggu 11 - Performance Optimization Coming Soon

Melakukan profiling, optimasi widget, caching, lazy loading, dan pengurangan bottleneck pada aplikasi.

#12 Minggu 12 - Testing & Quality Assurance Coming Soon

Menyusun unit test, widget test, dan integration test untuk menjaga kualitas serta mencegah regresi pada aplikasi.

#13 Minggu 13 - CI/CD & Automation Coming Soon

Membuat pipeline otomatis untuk build, test, dan release serta mengatur environment variable dan secret dengan aman.

#14 Minggu 14 - Deployment & Monitoring Coming Soon

Melakukan deployment beta, release management, monitoring aplikasi, dan analisis crash serta performa setelah rilis.

#15 Minggu 15 - Secure Mobile Development Coming Soon

Memahami OWASP Mobile Top 10, security hardening, privacy, secure storage, dan pencegahan celah keamanan aplikasi.

#16 Minggu 16 - Final Project Expo Coming Soon

Mendemonstrasikan proyek akhir, review arsitektur, deployment, testing, dan refleksi penggunaan AI secara bertanggung jawab.

1. What is AI Feature Integration?

AI features enable mobile apps to communicate with cloud AI models to provide intelligent services to users:

  • Chat assistant — real-time Q&A with LLM API
  • OCR — text extraction from images or documents
  • Speech-to-Text — convert voice input to text
  • Image Understanding — caption and image analysis via AI
  • Recommendation — personalized suggestions based on user data

2. AI Integration Architecture

+----------------+      HTTPS/wss      +----------------+
|   Flutter UI   | <-----------------> |  AI API Layer  |
|  (Chat, OCR,   |      (Dio/http)     |  (LLM, OCR,    |
|   STT, Image)  |                     |   STT, Vision) |
+----------------+                     +----------------+
        |                                      |
        | API Key (secure storage)             | Response
        v                                      v
+----------------+      Optional      +----------------+
|  Local Cache   | <-----------------> |   Backend    |
|  (Hive/SQLite) |     (batching)     |  (auth, log) |
+----------------+                     +----------------+
  • API keys are never stored directly in source code
  • Use flutter_secure_storage to store tokens/keys
  • Consider cost per request and rate limits
  • Apply local caching to reduce repeated AI API calls

Step 2: Create AI Service

Create lib/ai/ai_service.dart:

import 'dart:convert';
import 'package:http/http.dart' as http;
import 'package:flutter_secure_storage/flutter_secure_storage.dart';

class AiService {
  final _storage = const FlutterSecureStorage();
  final _apiUrl = 'https://generativelanguage.googleapis.com/v1beta/models/gemini-pro:generateContent';

  Future<String> ask(String question) async {
    final apiKey = await _storage.read(key: 'ai_api_key');
    if (apiKey == null || apiKey.isEmpty) {
      throw Exception('API key not available. Please set it in settings.');
    }

    final response = await http.post(
      Uri.parse('$_apiUrl?key=$apiKey'),
      headers: {'Content-Type': 'application/json'},
      body: jsonEncode({
        'contents': [{
          'parts': [{'text': question}]
        }]
      }),
    );

    if (response.statusCode == 200) {
      final data = jsonDecode(response.body);
      return data['candidates'][0]['content']['parts'][0]['text'];
    } else {
      throw Exception('Failed to call AI API: ${response.statusCode}');
    }
  }

  Future<void> saveApiKey(String key) async {
    await _storage.write(key: 'ai_api_key', value: key);
  }
}

Speech-to-Text

  • Convert to text via AI API
  • Use for: fast input, accessibility

Image Understanding

  • Upload image and ask AI for description
  • Use for: product description, object identification, accessibility

Risk and Mitigation Table

RiskMitigation
User data leakageNever send sensitive data to AI API
Cost spikeLimit requests per user/day, use local cache
API error / downShow friendly message, retry option, offline mode
Irrelevant responseApply validation and fallback to local data

Fallback Example

try {
  final response = await aiService.ask(question);
} catch (e) {
  showDialog(
    context: context,
    builder: (_) => AlertDialog(
